# Product

## Register

product

## Users

Indie animators, digital illustrators, motion designers, and web creators who want to sketch and produce frame-by-frame 2D animations directly in the browser without friction, heavy desktop installations, or complex licensing.

## Product Purpose

A high-precision, zero-lag browser-based 2D frame-by-frame animation studio. It treats 2D animation with the architectural discipline of a drafting table: fast strokes, instant onion-skinning, multi-layer timelines, real-time 60 FPS playback, and universal video export.

## Brand Personality

- Electric Blueprint Studio: technical precision, architectural boldness, unfiltered creative power
- High-contrast electric indigo canvas (`#1f00ff`) alternating with stark white cards and crisp hairline borders
- Confident engineering aesthetic: animation crafted like a technical schematic, not casual doodle software
- Zero fluff, uncompromising clarity

## Anti-references

- AI slop tropes: gradient text (`background-clip: text`), decorative grid overlays, faux glassmorphism (`backdrop-filter`), uniform cards
- Repetitive AI scaffold tells: tiny uppercase tracked eyebrows on every section, em dashes in copy, nested cards, excessive badge spam (`New`, `AI-Powered`, `Beta`), emojis in UI labels
- Legacy enterprise desktop bloat: labyrinthine dropdown hierarchies, unlabelled cryptic icon dumps, cramped panels
- Over-simplified toy UIs: massive bubbly touch controls that steal canvas drawing space and impede precise frame pacing
- Raster bitmap logos: pixelated PNG badges or arbitrary 3D spheres

## Design Principles

- Canvas First: The workspace and animation canvas are sacred; chrome and toolbars exist purely to serve the drawing hand.
- Hairline Blueprint Structure: Structure is defined by crisp 1px borders and stark surface alternation, never by muddy drop shadows.
- Single Accent Conversion: Electric indigo defines the brand universe; warm patch orange (`#ff622b`) is reserved exclusively for primary conversion and action moments.
- Zero Friction Play: Immediate feedback, fast tool switching, and instant playback loop without waiting or lag.
- Honest Affordances: Clean standard controls, readable technical readouts, and clear shortcuts.

## Accessibility & Inclusion

- WCAG AA contrast compliance across all UI chrome, controls, and active states (>= 4.5:1 for standard text, 12.8:1 on primary surfaces).
- Full keyboard shortcut accessibility for timeline navigation, playback controls, and tool switching.
- Respect `prefers-reduced-motion` on UI chrome and backdrop transitions while preserving intentional canvas playback.
